# Fibonacci Series (Python)

OOP exercise demonstrating a `Fibonacci` class that generates the Fibonacci sequence.

## Files
- `fibonacci.py` — `Fibonacci` class with `__init__` and `display()`
- `main.py` — Main program that gets user input and displays the series

## Class Design
**Fibonacci**
- `__init__(self, n)` — Stores number of terms
- `display()` — Prints first `n` Fibonacci numbers

## Run
```bash
python main.py
```
