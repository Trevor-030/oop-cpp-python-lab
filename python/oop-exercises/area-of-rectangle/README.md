# Area of Rectangle (Python)

OOP exercise demonstrating a `Rectangle` class with constructor and method.

## Files
- `rectangle.py` — `Rectangle` class with `__init__` and `calculate_area()`
- `main.py` — Main program that gets user input and calculates area

## Class Design
**Rectangle**
- `__init__(self, length, width)` — Initializes length and width
- `calculate_area()` — Returns `length * width`

## Run
```bash
python main.py
```

## Example Output
```
Enter the length: 5
Enter the width: 3
Area of the rectangle = 15
```
