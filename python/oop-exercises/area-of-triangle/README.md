# Area of Triangle (Python)

OOP exercise demonstrating a `Triangle` class with constructor and area calculation.

## Files
- `triangle.py` — `Triangle` class with `__init__` and `calculate_area()`
- `main.py` — Main program that gets user input and calculates area

## Class Design
**Triangle**
- `__init__(self, base, height)` — Initializes base and height
- `calculate_area()` — Returns `0.5 * base * height`

## Run
```bash
python main.py
```

## Example Output
```
Enter base: 10
Enter height: 5
Area of triangle = 25.0
```
