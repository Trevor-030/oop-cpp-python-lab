# Python OOP Exercises

Python implementations of the same exercises in `../../cpp/oop-exercises/` for side-by-side comparison.

## Exercises

| Exercise | Directory | Key Concept |
|---|---|---|
| Area of Rectangle | `area-of-rectangle/` | Class with `__init__`, method |
| Area of Triangle | `area-of-triangle/` | Class with `__init__`, method |
| Fahrenheit to Centigrade | `fahrenheit-to-centigrade/` | Unit conversion class |
| Fibonacci Series | `fibonacci-series/` | Sequence generation |
| Matrix | `matrix/` | Dynamic matrix, `alt-version/` alternative |
| Simple Interest | `simple-interest/` | Financial calculation |
| Quadratic Roots | `quadratic-roots/` | Math with discriminant, complex roots |
| Payroll System | `payroll-system/` | Inheritance, `alt-version/` matches C++ data |

## Run
```bash
cd <exercise-directory>
python main.py
```
