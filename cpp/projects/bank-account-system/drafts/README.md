- `v2_multi_account.cpp` — Added support for multiple accounts
- `v2_multi_account_revised.cpp` — Refined v2 with better structure
- `early-modular/` — First attempt at modular structure (incomplete)
  - `BankAccount.h` / `BankAccount.cpp`
  - `Customer.h` / `Customer.cpp`
  - `main.cpp`

## Purpose
These drafts show the evolution from a simple single-file program to the final modular architecture. They are preserved for reference and learning purposes.
